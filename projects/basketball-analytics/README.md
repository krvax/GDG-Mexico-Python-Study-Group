# 🏀 Proyecto Práctico: Analítica de Baloncesto — Cóatl

Este proyecto práctico de ciencia de datos utiliza estadísticas reales/simuladas de los entrenamientos del club deportivo comunitario **Cóatl Baloncesto** para aprender manipulación de datos en Python.

---

## 🎯 Objetivos de Aprendizaje
* Cargar archivos tabulares en formato CSV usando **Pandas**.
* Realizar operaciones matemáticas vectorizadas (porcentajes de efectividad).
* Filtrar, ordenar y agrupar DataFrames.
* Crear visualizaciones gráficas sencillas mediante **Matplotlib**.

---

## 📊 Estructura de los Datos (`stats.csv`)

El archivo [stats.csv](file:///home/mcarvaj/src/learning/courses/gdg-python-study-group/projects/basketball-analytics/stats.csv) contiene el rendimiento de 10 jugadores en su última sesión:

* `player`: Nombre del jugador.
* `shots_made`: Tiros encestados.
* `shots_attempted`: Tiros totales intentados.
* `rebounds`: Cantidad de rebotes capturados.
* `assists`: Pases que terminaron en enceste (asistencias).
* `minutes_played`: Minutos jugados por el deportista en la sesión.
